# Render hook proof

Install this bundle alongside horizon-machine-sample. On the server-thread world and again as a client of a dedicated server, place a `machine_sample:machine` and look at it. Confirm a magenta 96px square at the top left and a stone cube above the machine in screenshots. Check the client log for `render-proof: render_needs`, `render-proof: world_drawn`, and `render-proof: block_entity_submit`. Also verify the machine changes four cobblestone into four stone.
